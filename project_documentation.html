I. Interactive User Flow & Routing Guide

1. What happens when you click "New Car" or "Used Car" tabs?

1
State Trigger: Clicking the tab triggers setActiveTab('new' | 'used').
2
Hook Update: The active tab state updates inside the useCarFilter custom hook.
3
Dynamic Recalculation: The main page re-renders, recalculating card counts (e.g. SUV, Hatchback) and budget availabilities matching only that tab's state.

2. What happens when you click an Explore Card (Body Type or Budget)?

1
Click Bubble-up: The card calls its onClick prop, passing the card's specific filter name (e.g. 'SUV' or 'luxury').
2
Filter Application: The callback invokes handleFilterChange('bodyType' | 'budget', value) in Home.jsx, changing the filtering criteria inside the custom hook.
3
Smooth Scrolling: The page automatically scrolls to the listing grid via scrollToCatalog(), showing the filtered cars.

3. What happens when you click "Compare" on a vehicle card?

1
State Array Shift: The card invokes handleCompareToggle(car) in the parent Home.jsx.
2
Limit Check: If the car is not in the array and the array has less than 3 elements, it is added. If already present, it is filtered out.
3
Drawer Popup: The comparison drawer rises from the screen's bottom, rendering the comparison modal options.

5. Custom Filter Hook (src/hooks/useCarFilter.js) src/hooks/useCarFilter.js
This is the logic center. It bundles search input states, tab selections (new/used), dropdown filters, and calculates the filtered list using memoization. 
import { useState, useMemo } from 'react';

/* 
  Custom React Hook: useCarFilter
  Demonstrates:
  1. Custom Hooks (Lec 41-42): Bundling stateful logic for reusability.
  2. useMemo (Lec 36-40): Memoizing computed values to avoid unnecessary re-calculations on every render.
  3. Array Methods: Chaining .filter() and .map() with string operations (.toLowerCase(), .includes()).
*/
export function useCarFilter(initialCars) {
  // 1. Search Query state (text search input)
  const [searchQuery, setSearchQuery] = useState('');

  // 2. Active Tab state ('new' or 'used')
  const [activeTab, setActiveTab] = useState('new');

  // 3. Dropdown filters state
  const [filters, setFilters] = useState({
    brand: '',
    budget: '',
    bodyType: '',
    fuel: '',
    transmission: ''
  });

  // Handler to update a single key in the filters object
  const handleFilterChange = (key, value) => {
    setFilters((prev) => ({
      ...prev,
      [key]: value
    }));
  };

  // Reset all search parameters and filters to default
  const resetFilters = () => {
    setSearchQuery('');
    setFilters({
      brand: '',
      budget: '',
      bodyType: '',
      fuel: '',
      transmission: ''
    });
  };

  /* 
    Memoized filtered cars array
    Recalculates only when initialCars, searchQuery, activeTab, or filters change.
  */
  const filteredCars = useMemo(() => {
    return initialCars.filter((car) => {
      // A. Filter by Tab (New vs Used)
      const matchesTab = activeTab === 'new' ? !car.isUsed : car.isUsed;
      if (!matchesTab) return false;

      // B. Filter by Search Query (Name/Brand)
      if (searchQuery.trim() !== '') {
        const query = searchQuery.toLowerCase();
        const matchesName = car.name.toLowerCase().includes(query);
        const matchesBrand = car.brand.toLowerCase().includes(query);
        if (!matchesName && !matchesBrand) return false;
      }

      // C. Filter by Brand Dropdown
      if (filters.brand && car.brand !== filters.brand) {
        return false;
      }

      // D. Filter by Body Type Dropdown
      if (filters.bodyType && car.bodyType !== filters.bodyType) {
        return false;
      }

      // E. Filter by Fuel Type
      if (filters.fuel && car.fuel !== filters.fuel) {
        return false;
      }

      // F. Filter by Transmission
      if (filters.transmission && car.transmission !== filters.transmission) {
        return false;
      }

      // G. Filter by Budget Range
      if (filters.budget) {
        if (filters.budget === '500000') {
          if (car.price > 500000) return false;
        } else if (filters.budget === '1000000') {
          if (car.price <= 500000 || car.price > 1000000) return false;
        } else if (filters.budget === '1500000') {
          if (car.price <= 1000000 || car.price > 1500000) return false;
        } else if (filters.budget === '2000000') {
          if (car.price <= 1500000 || car.price > 2000000) return false;
        } else if (filters.budget === '3000000') {
          if (car.price <= 2000000 || car.price > 3000000) return false;
        } else if (filters.budget === 'luxury') {
          if (car.price <= 3000000) return false;
        }
      }

      return true; // Car matches all criteria
    });
  }, [initialCars, searchQuery, activeTab, filters]);

  return {
    searchQuery,
    setSearchQuery,
    activeTab,
    setActiveTab,
    filters,
    handleFilterChange,
    resetFilters,
    filteredCars
  };
}
How it works:
  • useCarFilter function: Receives the full cars array and returns all states and filters. This keeps the Home component code clean.
  • useMemo (Line 50): Caches the filtered array. The code inside useMemo will only re-execute if initialCars, searchQuery, activeTab, or filters change, preventing lag.
  • Budget checks (Line 84): Implements exact, non-overlapping price ranges to guarantee card counts match listing outputs.

    handleFilterChange('brand', brandName);

    scrollToCatalog();

  const handleCompareToggle = (car) => {

      setCompareCars(compareCars.filter((item) => item.id !== car.id));

      setCompareCars([...compareCars, car]);

    setCompareCars(compareCars.filter((item) => item.id !== car.id));
  };

  // Callback: Clear all selected cars
  const handleClearAllCompare = () => {
    setCompareCars([]);
  };

  // Callback: Open detailed specifications overlay modal
  const handleViewDetails = (car) => {
    setSelectedCarDetails(car);
  };

  // Callback: Close detailed specifications overlay modal
  const handleCloseDetails = () => {
    setSelectedCarDetails(null);
  };

  const isCarCompared = (carId) => compareCars.some((item) => item.id === carId);

  const getBudgetCount = (value) => {
    const isUsedTab = activeTab === 'used';
    const matchesTab = (car) => car.isUsed === isUsedTab;
    if (value === '500000') {
      return cars.filter(car => car.price <= 500000 && matchesTab(car)).length;
    }
    if (value === '1000000') {
      return cars.filter(car => car.price > 500000 && car.price <= 1000000 && matchesTab(car)).length;
    }
    if (value === '1500000') {
      return cars.filter(car => car.price > 1000000 && car.price <= 1500000 && matchesTab(car)).length;

export const formatIndianPrice = (price) => {
  if (price >= 10000000) {

  }
  return `₹ ${(price / 100000).toFixed(2)} Lakh`;
};
