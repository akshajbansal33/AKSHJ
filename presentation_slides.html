State Management: Lifting State Up Slide 05/11

The State Orchestrator Pattern

  • Parent component (`Home.jsx`) coordinates state values and shared data arrays.
  • Data is sent down to sub-components via read-only **Props**.
  • Interactions (clicks) bubble back up to the parent using **Callbacks**.

Coordinated States

  • Active Tab: ('new' vs 'used') toggling recalculates card inventory counts in real-time.
  • Compare Array: Stores comparison items globally.
  • Modal Select: Coordinates display values for overlay spec sheets.
React Hooks & Data Flow Slide 05
Presenter Speaking Script:

A core concept of React we implemented is 'Lifting State Up'. Instead of each component keeping its own isolated state, the state is lifted to 'Home.jsx'. For instance, when a user clicks 'Add to Compare' on a 'CarCard', that click event bubbles up to the 'Home' parent. The parent updates the comparison array, which then automatically flows down to update the bottom 'CompareBar' and check/uncheck the comparison checkboxes across all cards.

Logic Hook: useCarFilter Slide 06/11

Hook Responsibility

  • Separates calculations and filter business logic from visual HTML components.
  • Powers the search engine using React's state hooks.
  • Maintains search query strings, tab states, dropdown filters, and search modes.

Sequential Filtering Flow

1. Match Tab Type (New vs Used) 2. Evaluate Search input string 3. Match Brand & Body Style Dropdowns 4. Evaluate non-overlapping Budget limits 5. Apply Fuel & Transmission selections
Business Logic Separation Slide 06
Presenter Speaking Script:

We created a custom React hook called 'useCarFilter'. This hook acts as the brain of the search system. It keeps track of search terms and filters, and returns a memoized array of cars. The filter sequence is a chain: it first filters by new/used tabs, then text queries, followed by brand, body type, fuel, gearbox, and price. Lifting this logic into a hook keeps our JSX code clean and reusable.

UI Syncing & State Collisions Slide 07/11

The Challenge

Accumulated states on card clicks caused conflicting filters, returning zero search results (e.g. searching for a Tata SUV under 5 Lakhs).

The SearchBox mode ('budget' vs 'brand') was out-of-sync with homepage quick card clicks.

The Solution

  • Lifted searchMode State: Relocated searchMode from local SearchBox state up to the primary custom hook.
  • Self-Clearing Clicks: Handler clicks reset conflicting attributes:
    • Clicking Brand clears budget/body type and sets searchMode to 'brand'.
    • Clicking Budget clears brand/body type and sets searchMode to 'budget'.
    • Clicking Body Type clears brand/budget.
Conflict Resolution Slide 07
Presenter Speaking Script:

During development, we solved a critical state collision bug. When users clicked homepage categories, filters would accumulate and conflict, resulting in empty results (like selecting Tata and then looking for cars under 5 Lakh). To solve this, we synced the search mode state globally and updated our card click handlers. Now, clicking a category card automatically clears conflicting filters and updates the search box dropdown, ensuring a seamless, bug-free exploration experience.

Theme Engine & FOUC Prevention Slide 09/11

Global Theme Toggle

  • Header toggle switches themes across all components.
  • Stores choices in browser `localStorage` for preference persistence.
  • Dynamic theme application using CSS variables.

Preventing Page Flicker

  • FOUC (Flash of Unstyled Content): React themes load asynchronously, causing white flashes on reload.
  • Blocking Render Script: Injected a small blocking script inside the HTML `` tag.
  • Reads storage and applies the `data-theme` attribute *before* React loads.
Flicker-Free Theme Toggling Slide 09
Presenter Speaking Script:

To deliver a premium feel, we built a global theme engine for light and dark modes. To solve the common issue where a page flashes white on reload in dark mode—known as Flash of Unstyled Content (FOUC)—we wrote a small, blocking script in the head of our index.html. This script reads the saved theme from the browser's storage and applies the data-theme attribute before React starts parsing, ensuring a seamless dark loading experience.

Performance & Core Concepts Slide 10/11

React Performance Optimization

  • useMemo Hook: Memoizes the filtered cars array. Skips heavy recalculations on text typing unless dependencies update.
  • Image Lazy Loading: Grid images use `loading="lazy"` to delay fetching until scrolling near them.

JavaScript Syllabus Concepts

  • ES6 Modules: Exporting/importing database entities and utilities.
  • Arrays & Objects: Iterating lists using `.map()`, `.filter()`, and `.some()`.
  • Destructuring: Destructuring states and properties.
Optimization & Standards Slide 10
Presenter Speaking Script:

We optimized performance using React's 'useMemo' hook. The filtering algorithm only recalculates if the actual filters or search inputs change, preventing re-calculation lag on text changes.
